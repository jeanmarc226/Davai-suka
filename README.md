# Davai Suka

Application web progressive (PWA) de suivi d'entraînement quotidien. Les séances, le programme et l'estimation des calories restent dans le navigateur (localStorage). Aucune compilation : HTML, CSS et JavaScript statiques, servis depuis la racine de la branche `main`.

## Installation

Ouvrir l'application : [https://jeanmarc226.github.io/Davai-suka/](https://jeanmarc226.github.io/Davai-suka/)

Dans Chrome (Android) ou Safari (iOS) : menu du navigateur, puis « Ajouter à l'écran d'accueil » / « Installer l'application ».

Le mode d'emploi détaillé est dans [LISEZMOI.md](LISEZMOI.md).
